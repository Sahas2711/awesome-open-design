# Café Menu Design

A design example for creating a café menu using Open Design principles.

## Description

This example demonstrates how to create a professional café menu with A4 layout and Instagram story format. The design includes color palette, typography, and layout suitable for a modern café brand.

## Usage

1. Open this example in your preferred design tool
2. Customize the text and colors to match your café's branding
3. Export as needed for print or digital use

## Output Formats

- **A4 Menu**: Full-size printable menu
- **Instagram Story**: Vertical format for social media promotion
