# awesome-open-design Contribution Guidelines

Thank you for contributing to awesome-open-design! This repository contains curated open design examples for the Open Design framework.

## How to Contribute

1. **Fork the repository** and create a new branch from `main`
2. **Add your design example** following the structure below
3. **Submit a Pull Request** with a clear description of your changes

## Directory Structure

```
awesome-open-design/
├── CONTRIBUTING.md
├── examples/
│   ├── cafe-menu/
│   │   ├── SKILL.md
│   │   ├── open-design.json
│   │   └── example.html
│   ├── ...
│   └── README.md
```

## Required Files for Each Example

### `SKILL.md`
- Description of the skill/category
- Prerequisites
- How to use the example

### `open-design.json`
- Metadata about the design example
- Includes: title, description, tags, related skills
- Follow the format of existing examples

### `example.html`
- The actual design example
- Should demonstrate the skill effectively
- Can be A4 format, Instagram story, or other formats

## Development

- Ensure all HTML validates
- Keep dependencies minimal
- Follow accessible design practices
- Test with different viewport sizes
